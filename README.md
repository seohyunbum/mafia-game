# mafia-game

역할 기반 심리 추리 게임. 밤에는 마피아가 사람을 죽이고, 낮에는 살아있는 사람들이
토론·투표로 마피아를 색출한다. 여기에 **변신**(마피아가 시민 얼굴을 뒤집어써서 투표를
엉뚱한 곳으로 돌린다)과 **3파전**(시민팀 / 마피아팀 / 교주팀)이 얹힌다.

전원 시작 HP 2 — 한 번 잘못 지목당해도 즉사하지 않는다는 것이 이 게임의 핵심 감각이다.

## 현재 상태

**설계 단계.** 코드는 아직 없다. 설계 정본과 데이터 스키마 골격만 있다.

| 경로 | 내용 |
|---|---|
| [`docs/DESIGN.md`](docs/DESIGN.md) | **규칙의 정본.** 확정(✅)/해석(🟡)/미정(⬜)을 구분해 기록 |
| [`data/roles.json`](data/roles.json) | 역할·진영 정의 (미확정 값은 `null`) |
| [`data/rules.json`](data/rules.json) | 전역 규칙 수치 (미확정 값은 `null`) |

## 코어 규칙 구현 전에 필요한 답

`docs/DESIGN.md` §10 의 **Q1~Q3** 이 코어 규칙의 형태를 결정한다.

- **Q1** 변신한 마피아를 지목했을 때 HP -1 을 받는 건 흉내낸 원본 시민인가, 마피아 본인인가?
- **Q2** 밤 살해는 즉사인가 HP -1 인가?
- **Q3** 낮 투표로 지목된 사람은 즉시 처형인가 HP -1 인가? 최다득표 1명만인가?

## 작업 규칙

1. **`docs/DESIGN.md` 가 정본이다.** 코드·데이터가 문서와 어긋나면 문서를 먼저 고친다.
2. **밸런스 수치 하드코딩 금지** — 전부 `data/*.json`.
3. **미확정 값을 임의로 채우지 않는다** — 문서는 ⬜, JSON 은 `null` 로 남긴다.
   임의값을 넣어 확정처럼 보이게 만드는 것이 가장 비싼 실수다.
4. 순수 규칙 코어(UI·엔진 의존 0)를 먼저 만들고, UI 는 마지막에 얇게 붙인다.
