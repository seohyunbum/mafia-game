# 마피아 게임 — 밤의 의회

가족과 함께 즐기는 12인 역할 기반 사회 추리 웹게임입니다. 시민팀·마피아팀·교주팀이
밤의 비밀 행동과 낮의 재판으로 마지막 승리를 겨룹니다.

## 실행 표면 — 아이콘은 배포본을 엽니다 (표준)

**표준 실행 경로는 바탕화면 아이콘이 여는 <https://seohyunbum.github.io/mafia-game/> 이고,
그 화면은 `gh-pages` 브랜치의 정적 배포본입니다.**

아이콘은 로컬 파일을 읽지 않습니다. 그래서 **로컬을 고쳐도 배포하지 않으면 아이콘 화면은
바뀌지 않습니다.** 지금 서비스 중인 소스 커밋은
<https://seohyunbum.github.io/mafia-game/source-commit.txt> 에서 확인할 수 있습니다.

## 구성 — 12인 3진영

| 진영 | 구성 | 승리 조건 |
|---|---|---|
| 시민팀 8 | 시민 6 · 경찰 1 · 의사 1 | 마피아팀과 교주팀을 모두 몰아낸다 |
| 마피아팀 3 | 마피아 1 · 폭탄마 1 · 스나이퍼 1 | 나머지 전원을 죽인다 |
| 교주팀 1 | 교주 1 | 두 명만 남을 때까지 사제를 늘린다 |

- **경찰** 밤마다 한 명을 검사합니다. 결과는 **누가 검사했는지 숨긴 채** 모두에게 공개됩니다.
- **의사** 밤에 한 명을 지켜 그 밤의 살해·폭발 피해를 막습니다.
- **마피아** 밤에 한 명을 즉사시키고, 아침에 시민의 얼굴을 뒤집어씁니다. 변신한 채 처형되면
  피해가 흉내낸 시민에게 흘러가고 본인도 함께 처형됩니다.
- **폭탄마** 후보 3명을 고르고 그중 1명을 찍습니다. 찍힌 사람 즉사, 나머지는 체력 1 감소.
  게임당 2회. 후보에 같은 편을 넣을 수 없으므로 **후보 명단 자체가 결백의 증거**가 됩니다.
- **스나이퍼** 페이즈에 묶이지 않는 단 한 발. 변론 중에도 쏠 수 있습니다.
- **교주** 짝수 밤마다 한 명을 사제로 전향시킵니다. 사제는 원래 역할을 유지한 채 편이 바뀝니다.

하루는 **밤(사회자가 직업을 순서대로 호출) → 새벽 → 아침 → 낮 토론·지목 → 재판 → 해질녘**
으로 흐릅니다. 전원 체력 2이고, 밤 살해·처형·저격은 즉사입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

표시되는 주소(기본 <http://localhost:3000>)를 브라우저에서 엽니다.

## 검증

```bash
node --test tests/rules/*.test.ts tests/flow/flow.test.ts
```

`tests/rules` 는 규칙을, `tests/flow` 는 **흐름이 끊기지 않는지**를 봅니다. 후자는 AI 가 12좌석
전부를 잡고 판을 끝까지 돌려 진행 정지·규칙 오류·진영 승률을 회귀로 지킵니다.

## 배포

```bash
node scripts/build-pages.mjs
```

`dist/pages/` 에 Pages 배포본이 조립됩니다. 스크립트가 하는 일은 셋입니다.

1. `npm run build` — SSR 산출물(`dist/client`)을 만듭니다.
2. 프로덕션 서버를 잠깐 띄워 `/` 를 받아 **정적 `index.html` 로 굳힙니다** (SSR 앱이라
   빌드만으로는 `index.html` 이 나오지 않습니다).
3. 루트 절대 경로(`/assets/...`)를 Pages 하위 경로(`/mafia-game/assets/...`)로 바꿉니다.
   이걸 빼먹으면 사이트가 열리되 자산을 전부 404 로 받습니다.

이어서 `dist/pages/` 의 내용을 `gh-pages` 브랜치로 올리면 아이콘 화면이 갱신됩니다.

## 규칙 정본

확정 규칙은 [`docs/DESIGN.md`](docs/DESIGN.md), 수치는 [`data/`](data/) JSON 이 정본입니다.
해석으로 채운 항목(🟡)은 전부 `data/rules.json` 값으로 내려와 있고, 각 값의 근거와 측정치가
`_status` 주석에 남아 있습니다.

## 온라인 듀오

6자리 방 코드로 두 사람이 같은 진영이 되어 플레이하는 WebRTC P2P 모드입니다.
**현재 정비 중입니다** — 호스트 권위 프로토콜이 옛 행동 모델에 묶여 있어, 새 제출 모델로
옮기는 작업이 남아 있습니다. 전송 계층(`lib/online/`)은 그대로 보존돼 있습니다.
