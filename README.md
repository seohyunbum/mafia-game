# mafia-game

역할 기반 심리 추리 게임. 밤에는 마피아가 사람을 죽이고, 낮에는 살아있는 사람들이
토론·투표로 마피아를 색출한다. 여기에 **변신**(마피아가 시민 얼굴을 뒤집어써서 투표를
엉뚱한 곳으로 돌린다)과 **3파전**(시민팀 / 마피아팀 / 교주팀)이 얹힌다.

## 확정된 핵심 규칙

- 전원 시작 **HP 2**.
- **밤 살해 = 즉사** (HP 무시). 거를 수 없다 — 안 쓰면 본인이 죽는다.
- **낮 = 2단계** — 지목 투표로 피고를 세우고, 피고가 변론한 뒤 **살린다/죽인다** 투표로 생사를 정한다.
- **변신한 마피아를 죽이기로 하면, 흉내낸 원본 시민이 대신 HP 1 을 잃는다.** 마피아 본인은 무피해.
  → 변신은 은신기가 아니라 **공격기**다. 시민팀이 속을수록 스스로를 깎는다.
- **마피아팀은 서로를 안다.** 시민팀은 능력자끼리도 서로를 모른다.

### 세 진영, 세 가지 이기는 방법

| 진영 | 이기는 방법 |
|---|---|
| **마피아팀** | **죽여서** — 나머지 전원 사망 |
| **시민팀** | **찾아서** — 마피아팀·교주팀을 색출해 처형 |
| **교주팀** | **갈아치워서** — 죽이지 않고 전향시킨다. 두 명 빼고 모두 사제가 되면 승리 |

### 밤은 사회자가 직업을 하나씩 깨운다

밤이 되면 **모두 자기 방으로 들어간다.** 자기 직업이 불리면 방에서 나와 능력을 쓴다.

```
[모두 방으로]
"마피아는 일어나주세요"    90초 안에 살해 지목       안 하면 사망
"스나이퍼는 일어나주세요"  쏠 수도, 안 쏠 수도       면제
"경찰은 일어나주세요"      90초 안에 검사            안 하면 사망
"의사는 일어나주세요"      90초 안에 보호            안 하면 사망
"시민은 일어나주세요"      능력이 없다               면제
"교주는 일어나주세요"      짝수 밤에만 호출          안 하면 사망
→ 밤 끝 → 5분 시체 조사·행동 → 투표
```

**밤에 가만히 있는 것 자체가 죽음이다.** 능력자는 매 밤 흔적을 남겨야 하고, 소극적으로 숨을 수 없다.

**시민도 호출한다.** 능력이 없어도 부른다 — 건너뛰면 호출 순서만 듣고 그 판의 구성을 읽을 수
있기 때문이다. 시민이 나와서 아무것도 하지 않는 것이 곧 위장이 된다.

### 역할

| 진영 | 역할 | 능력 |
|---|---|---|
| 시민팀 | 시민 | 없음 — 토론·투표만 |
| 시민팀 | **경찰** | 밤에 한 명 검사 → 마피아팀인지 아닌지 |
| 시민팀 | **의사** | 밤에 한 명 보호 → 그 사람은 그 밤 피해를 받지 않는다 |
| 마피아팀 | 마피아 | 밤에 한 명 즉사 + 아침에 랜덤 시민으로 변신 |
| 마피아팀 | **폭탄마** | 밤에 **후보 3명 중 1명을 찍는다 — 찍힌 사람 즉사, 나머지 둘 HP -1** |
| 마피아팀 | **스나이퍼** | **밤이든 낮이든 어디서나** 한 명 즉사. 페이즈에 묶이지 않는 유일한 능력 |
| 교주팀 | **교주** | **짝수 밤에만** 움직인다. 한 명을 사제로 만든다 |
| 교주팀 | 사제 | 전향된 사람. 원래 역할을 유지한 채 교주팀이 된다 (역할이 아니라 상태) |

**HP 2 를 깎는 경로는 둘** — 폭탄 후보에 오르거나, 변신에 속아 엉뚱한 사람을 치거나.
그래서 상처가 곧 공개 정보이고, 다친 사람은 다음 한 방에 죽는다.

## 현재 상태

**세 진영 규칙 코어 + 사회자 진행 화면 구현 완료.**
남은 공백은 규칙이 아니라 **구성** — 몇 명이서 하는지, 진영 비율.

| 경로 | 내용 |
|---|---|
| [`docs/DESIGN.md`](docs/DESIGN.md) | **규칙의 정본.** 확정(✅)/해석(🟡)/미정(⬜)을 구분해 기록 |
| [`data/rules.json`](data/rules.json) | 전역 규칙 수치 — 해석으로 채운 값도 전부 여기 있다 |
| [`data/roles.json`](data/roles.json) | 역할·진영 정의 |
| `src/core/` | 순수 규칙 엔진 (화면·엔진 의존 0, 무작위성은 주입) |
| `src/ui/` | 사회자 진행 화면 (아래 참조) |
| `tests/` | 147개 테스트 |

미구현: AI 플레이어, 그리고 규칙 변형 몇 개(자동 폭발·의사 부활 등 — `docs/DESIGN.md` §10.3).

## 화면 — 사회자 진행판

```bash
npm install
npm run verify   # typecheck + test
npm run dev      # 개발 서버
npm run build    # dist/single.html — 파일 하나로 열리는 배포본
```

시작하면 **배역 봉투**를 한 사람씩 돌려가며 확인한다. 밀랍 봉인을 떼면 자기 직업과
"아는 사람"이 나온다 — 마피아팀은 여기서 서로를 확인한다.

아트 디렉션은 **1930년대 인쇄물·수배전단 느와르**다. 같은 사람이 만든 다른 저장소
(`blaster`·`wave-arena`)가 둥근 카드 + 산세리프 + 네온/파스텔 3D UI 라서, 의도적으로 정반대로 갔다:
모서리 0 · 명조 세리프 · 종이와 잉크 · 활판 오프셋 · 완전 평면.

- **밤은 문이 늘어선 복도**다. 호출받으면 문이 열리고 인물이 문간에 선다. 능력의 대상은 방 안에
  있는 사람이라, 대상 선택이 카드 그리드가 아니라 **문 고르기**다. 죽은 방은 판자로 막힌다.
- **외부 리소스 0.** 폰트는 시스템, 종이 질감은 CSS 그라디언트, 인물은 절차적 SVG(`portrait.ts`).
  오프라인에서도 그대로 나오고 링크 하나로 공유된다.
- **밤에는 종이가 어두워진다.** 색을 반전하는 게 아니라 암실등을 덮는 방식이라 인쇄물 느낌이 유지된다.
- **HP 는 카드의 빗금**으로 보인다. 상처가 곧 공개 정보라는 규칙(§1)을 화면이 그대로 드러낸다.
- **새벽은 조간신문**이다. 밤에 벌어진 일이 1면 기사로 나온다.
- 화면은 규칙을 판정하지 않는다. `src/core` 가 정본이고 UI 는 상태를 그리고 행동을 전달만 한다.
  **시간을 재는 것만 UI 의 책임**이다 (§6.1 — 코어는 시계를 갖지 않는다).

## 작업 규칙

1. **`docs/DESIGN.md` 가 정본이다.** 코드·데이터가 문서와 어긋나면 문서를 먼저 고친다.
2. **밸런스 수치 하드코딩 금지** — 전부 `data/*.json`.
3. **미확정 값을 임의로 채우지 않는다.** 문서는 ⬜/🟡, JSON 은 `null`.
   해석으로 채운 값은 반드시 `_*_status` 에 `interpretation` 으로 표시해 확정 규칙과 구분한다.
4. **정의 데이터는 fail-fast.** 규칙 값이 없거나 모르는 값이면 조용한 기본값 대신 기동을 실패시킨다.
5. 순수 규칙 코어를 먼저 만들고, UI 는 마지막에 얇게 붙인다.
6. 커밋 전 `npm run verify` 녹색.
